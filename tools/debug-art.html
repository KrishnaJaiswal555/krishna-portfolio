Artwork diagnostic

Runs the site's real art() / artSources() against the real content.js. A control row loads the same files with a plain <img>, so the loader and the file can be told apart.

1. Control — plain <img>, no JavaScript loader

If these appear, the files, paths and MIME types are all fine.

2. The real loader — art(project, artSources(project))

Each call is raced against a 4-second timer. TIMEOUT means the promise never settled — neither onload nor onerror fired — which is the deadlock a detached loading="lazy" image produces. That state renders nothing and logs nothing.
